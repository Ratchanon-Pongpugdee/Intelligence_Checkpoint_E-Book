# 2. ข้อมูลเดินทางอย่างไร

การติดตามข้อมูลช่วยให้เห็นว่าความเสี่ยงไม่ได้อยู่เฉพาะตอนเก็บข้อมูล แต่อาจเกิดตอนส่งต่อ เชื่อมโยง เก็บรักษา ค้นย้อนหลัง หรือใช้ข้อมูลเพื่อวัตถุประสงค์อื่น

## วงจรข้อมูลอย่างย่อ

1. **เก็บ:** กล้องหรือเครื่องอ่านรับภาพ รหัส หรือข้อมูลที่เกี่ยวข้องกับรถและอุปกรณ์
2. **แปลง:** ซอฟต์แวร์แปลงภาพเป็นข้อความหรือสร้างเหตุการณ์จากรหัสที่อ่านได้
3. **ส่ง:** อุปกรณ์ส่งข้อมูลผ่านเครือข่ายไปยังระบบส่วนกลางหรือหน่วยงานที่เกี่ยวข้อง
4. **เปรียบเทียบ:** ระบบค้นหรือเปรียบเทียบกับรายการอ้างอิงตามสิทธิและวัตถุประสงค์ที่กำหนด
5. **แจ้งผล:** ส่งผลจับคู่หรือสัญญาณเตือนให้เจ้าหน้าที่ตรวจทาน พร้อมแสดงความไม่แน่นอน
6. **ตัดสินใจและจัดการ:** เจ้าหน้าที่พิจารณาบริบท บันทึกเหตุผล และลบหรือเก็บข้อมูลตามกำหนด

## ทำบัญชีข้อมูล

ก่อนสร้างระบบจริง วิศวกรควรทำบัญชีข้อมูลที่ตอบคำถามเหล่านี้ให้ครบ:

| คำถาม            | ตัวอย่างสิ่งที่ต้องระบุ                                         |
| ---------------- | --------------------------------------------------------------- |
| เก็บอะไร         | ภาพ ป้ายทะเบียน เวลา จุดตรวจ รหัสอุปกรณ์ หรือผลการจับคู่        |
| เก็บเพื่ออะไร    | วัตถุประสงค์เฉพาะที่ตรวจสอบได้ ไม่ใช้คำกว้างอย่าง “เผื่อจำเป็น” |
| ใครเป็นผู้ควบคุม | หน่วยงานที่กำหนดวัตถุประสงค์และผู้ประมวลผลข้อมูล                |
| ใครเข้าถึงได้    | บทบาท สิทธิ ระยะเวลา และการบันทึกการเข้าถึง                     |
| เก็บนานเท่าใด    | ระยะเวลาตามความจำเป็น พร้อมกระบวนการลบและตรวจสอบการลบ           |
| ส่งต่อให้ใคร     | ผู้รับข้อมูล เหตุผล ช่องทาง และข้อจำกัดการใช้ซ้ำ                |

## หลักลดข้อมูล

หากเป้าหมายคือค้นหาเหตุการณ์เฉพาะ อาจไม่จำเป็นต้องเก็บประวัติการเดินทางของทุกคนอย่างถาวร พิจารณาเก็บเฉพาะข้อมูลที่จำเป็น จำกัดผู้เข้าถึง กำหนดอายุข้อมูล และแยกข้อมูลระบุตัวบุคคลออกจากข้อมูลวิเคราะห์เมื่อทำได้

> **จุดออกแบบสำคัญ:** เมื่อไม่มีการจับคู่ ระบบควรลบข้อมูลโดยเร็วตามนโยบายที่ตรวจสอบได้ ไม่ใช่เก็บไว้โดยไม่มีวันสิ้นสุดเพียงเพราะพื้นที่จัดเก็บมีราคาถูก
