# อภิธานศัพท์และแหล่งอ่านต่อ

## อภิธานศัพท์

| คำ                | ความหมายโดยย่อ                                                               |
| ----------------- | ---------------------------------------------------------------------------- |
| RFID              | เทคโนโลยีระบุข้อมูลผ่านคลื่นวิทยุ ใช้อ่านข้อมูลจากแท็กด้วยเครื่องอ่าน        |
| IMSI              | หมายเลขระบุตัวสมาชิกในเครือข่ายโทรศัพท์มือถือ ซึ่งสัมพันธ์กับซิม/บัญชีบริการ |
| IMEI              | หมายเลขระบุอุปกรณ์โทรศัพท์เคลื่อนที่                                         |
| False positive    | ระบบแจ้งว่าพบสิ่งที่ค้นหา ทั้งที่ความจริงไม่ใช่                              |
| False negative    | ระบบไม่แจ้งพบ ทั้งที่มีสิ่งที่ค้นหาอยู่                                      |
| Data minimization | เก็บและใช้ข้อมูลเท่าที่จำเป็นต่อวัตถุประสงค์ที่ระบุ                          |
| Audit log         | บันทึกว่าใครเข้าถึงหรือเปลี่ยนแปลงข้อมูล เมื่อใด และทำอะไร                   |
| Threat model      | การวิเคราะห์ทรัพย์สิน ผู้คุกคาม ช่องโหว่ และผลกระทบที่อาจเกิด                |

## เอกสารกรณีศึกษา

เอกสารประกอบที่ให้มาคือ _จรรยาบรรณวิชาชีพด้านวิศวกรรมคอมพิวเตอร์ ตอน ด่านอัจฉริยะ_ และชุดภาพระบบที่อยู่ในโฟลเดอร์ `assets` คู่มือนี้ใช้เอกสารดังกล่าวเป็นบริบทการเรียนรู้ ไม่ถือว่าข้อความหรือภาพสะท้อนสถานการณ์ปัจจุบันโดยอัตโนมัติ

## แหล่งอ่านต่อ

- ตรวจสอบกฎหมายคุ้มครองข้อมูลส่วนบุคคลและแนวปฏิบัติจากหน่วยงานภาครัฐของประเทศไทยฉบับล่าสุดก่อนใช้อ้างอิง
- อ่านแนวทางการประเมินผลกระทบด้านข้อมูลส่วนบุคคล (DPIA) และแนวปฏิบัติด้านความมั่นคงปลอดภัยจากหน่วยงานกำกับดูแลที่เกี่ยวข้อง
- เปรียบเทียบกรอบจริยธรรมวิชาชีพคอมพิวเตอร์ เช่น ACM Code of Ethics และแนวทางประเมินความเสี่ยงของระบบ AI จากแหล่งมาตรฐานที่เชื่อถือได้

> ข้อความในคู่มือนี้เป็นสื่อการศึกษา ไม่ใช่คำแนะนำทางกฎหมาย และควรปรับปรุงแหล่งอ้างอิงทุกครั้งที่มีการเปลี่ยนแปลงกฎหมายหรือนโยบาย
