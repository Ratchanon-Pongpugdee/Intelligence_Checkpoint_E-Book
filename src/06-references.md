# อภิธานศัพท์และแหล่งอ่านต่อ

## อภิธานศัพท์

| คำ                | ความหมายโดยย่อ                                                               |
| ----------------- | ---------------------------------------------------------------------------- |
| RFID              | เทคโนโลยีระบุข้อมูลผ่านคลื่นวิทยุ ใช้อ่านข้อมูลจากแท็กด้วยเครื่องอ่าน        |
| IMSI              | หมายเลขระบุตัวสมาชิกในเครือข่ายโทรศัพท์มือถือ ซึ่งสัมพันธ์กับซิม/บัญชีบริการ |
| IMEI              | หมายเลขระบุอุปกรณ์โทรศัพท์เคลื่อนที่                                         |
| False positive    | ระบบแจ้งว่าพบสิ่งที่ค้นหา ทั้งที่ความจริงไม่ใช่                              |
| False negative    | ระบบไม่แจ้งพบ ทั้งที่มีสิ่งที่ค้นหาอยู่                                      |
| Data minimization | เก็บและใช้ข้อมูลเท่าที่จำเป็นต่อวัตถุประสงค์ที่ระบุ                          |
| Audit log         | บันทึกว่าใครเข้าถึงหรือเปลี่ยนแปลงข้อมูล เมื่อใด และทำอะไร                   |
| Threat model      | การวิเคราะห์ทรัพย์สิน ผู้คุกคาม ช่องโหว่ และผลกระทบที่อาจเกิด                |

## เอกสารกรณีศึกษา

เอกสารประกอบที่ให้มาคือ _จรรยาบรรณวิชาชีพด้านวิศวกรรมคอมพิวเตอร์ ตอน ด่านอัจฉริยะ_ และชุดภาพระบบที่อยู่ในโฟลเดอร์ `assets` คู่มือนี้ใช้เอกสารดังกล่าวเป็นบริบทการเรียนรู้ ไม่ถือว่าข้อความหรือภาพสะท้อนสถานการณ์ปัจจุบันโดยอัตโนมัติ

## แหล่งอ่านต่อ

- [สำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล (สคส.)](https://www.pdpc.or.th/) สำหรับค้นกฎหมาย แนวปฏิบัติ และประกาศทางการของประเทศไทยฉบับปัจจุบัน
- [ACM Code of Ethics and Professional Conduct](https://www.acm.org/code-of-ethics) โดยเฉพาะข้อ 1.2 (หลีกเลี่ยงอันตราย), 1.4 (ความเป็นธรรม), 1.6 (ความเป็นส่วนตัว) และ 2.5 (ประเมินความเสี่ยงและผลกระทบ)
- [NIST AI Risk Management Framework](https://www.nist.gov/itl/ai-risk-management-framework) เป็นกรอบสมัครใจสำหรับจัดการความเสี่ยงของระบบ AI หากระบบที่ศึกษาใช้ AI จริง ไม่ใช่ข้อกำหนดกฎหมายไทย
- [เอกสาร mdBook](https://rust-lang.github.io/mdBook/) สำหรับผู้เรียนที่ต้องการดูเครื่องมือที่ใช้จัดทำคู่มือ

> แหล่งข้อมูลออนไลน์ตรวจสอบเมื่อ 28 กันยายน 2026 ข้อความในคู่มือนี้เป็นสื่อการศึกษา ไม่ใช่คำแนะนำทางกฎหมาย ควรตรวจวันที่และฉบับของกฎหมายจากแหล่งทางการก่อนนำไปอ้างอิง
