# ด่านอัจฉริยะ

## คู่มือจริยธรรมและวิศวกรรมคอมพิวเตอร์

หนังสืออิเล็กทรอนิกส์ภาษาไทยสำหรับใช้ประกอบการเรียนรู้และอภิปรายกรณีศึกษาระบบด่านอัจฉริยะ โดยพิจารณาระบบในฐานะการทำงานร่วมกันของอุปกรณ์ ซอฟต์แวร์ ฐานข้อมูล เครือข่าย เจ้าหน้าที่ และผู้ได้รับผลกระทบ

เนื้อหาพาผู้อ่านติดตามการเก็บและใช้ข้อมูล ตั้งแต่กล้องอ่านป้ายทะเบียนและ RFID ไปจนถึงการตรวจสอบผลแจ้งเตือน พร้อมชวนคิดถึงความเป็นส่วนตัว ความปลอดภัย ความเป็นธรรม และความรับผิดชอบเมื่อระบบผิดพลาด หนังสือมุ่งใช้เป็นสื่อการศึกษา ไม่ใช่ข้อกำหนดสำหรับนำระบบไปติดตั้งหรือคำแนะนำทางกฎหมาย

## วัตถุประสงค์การเรียนรู้

เมื่ออ่านและทำกิจกรรมประกอบแล้ว ผู้อ่านจะสามารถ:

- อธิบายองค์ประกอบและลำดับการทำงานของระบบด่านอัจฉริยะ
- ระบุข้อมูลส่วนบุคคล ผู้เกี่ยวข้อง และความเสี่ยงตลอดวงจรข้อมูล
- วิเคราะห์ประโยชน์และผลกระทบต่อผู้ได้รับผลกระทบกลุ่มต่าง ๆ
- เสนอแนวทางออกแบบและมาตรการตรวจสอบที่สมดุลระหว่างความปลอดภัย สิทธิ และความเป็นส่วนตัว

## เนื้อหา

1. [มองระบบในฐานะวิศวกร](src/01-system.md): องค์ประกอบ ขอบเขต และผู้เกี่ยวข้อง
2. [ข้อมูลเดินทางอย่างไร](src/02-data-flow.md): วงจรข้อมูล การส่งต่อ และการลดข้อมูล
3. [ประโยชน์ ความเสี่ยง และผู้ได้รับผลกระทบ](src/03-ethics.md): ความผิดพลาด อคติ การเฝ้าระวัง และการใช้ข้อมูลผิดวัตถุประสงค์
4. [ออกแบบระบบอย่างรับผิดชอบ](src/04-engineering.md): หลักการจริยธรรมที่แปลงเป็นข้อกำหนดและมาตรการตรวจสอบได้
5. [กิจกรรมอภิปราย](src/05-activity.md): สถานการณ์จำลองสำหรับการทำงานกลุ่ม
6. [อภิธานศัพท์และแหล่งอ่านต่อ](src/06-references.md): คำศัพท์และแนวทางค้นคว้าเพิ่มเติม

## เริ่มอ่าน

สามารถเปิดหนังสือฉบับเผยแพร่บน GitHub Pages ได้จากหน้า **About** ของ repository หากยังไม่ได้ตั้งค่า URL ให้เปิดอ่านจากไฟล์เริ่มต้น [src/index.md](src/index.md) หรือสร้างหนังสือในเครื่องตามขั้นตอนด้านล่าง

### อ่านและ build ในเครื่อง

โปรเจกต์นี้ใช้ [mdBook](https://rust-lang.github.io/mdBook/) โดย workflow สำหรับเผยแพร่ติดตั้ง mdBook เวอร์ชัน `0.5.4` หากยังไม่มี mdBook ให้ติดตั้งตาม [คู่มือการติดตั้ง](https://rust-lang.github.io/mdBook/guide/installation.html) แล้วรันคำสั่งจากโฟลเดอร์รากของ repository:

```sh
mdbook serve --open
```

คำสั่งนี้เปิดเว็บเซิร์ฟเวอร์สำหรับอ่านและดูการเปลี่ยนแปลงระหว่างแก้ไขเนื้อหา หากต้องการ build ไฟล์สำหรับเผยแพร่:

```sh
mdbook build
```

ไฟล์ผลลัพธ์จะอยู่ในโฟลเดอร์ `book/` ซึ่งสร้างขึ้นเมื่อ build สำเร็จ

## เผยแพร่ด้วย GitHub Pages

ไฟล์ workflow ที่ `.github/workflows/pages.yml` จะ build หนังสือและเผยแพร่ผ่าน GitHub Pages เมื่อมีการ push ไปยัง branch `Beta` หรือเมื่อสั่ง workflow ด้วยตนเองจากแท็บ **Actions** ใน GitHub ก่อนใช้งาน ให้เปิด GitHub Pages ของ repository และเลือก **GitHub Actions** เป็นแหล่ง deploy จากนั้นดู URL ของเว็บไซต์ได้ใน workflow run หรือการตั้งค่า Pages

## โครงสร้างโปรเจกต์

```text
.
├── .github/workflows/pages.yml  # build และ deploy ไปยัง GitHub Pages
├── assets/                      # ภาพประกอบกรณีศึกษา
├── book.toml                    # ชื่อหนังสือและการตั้งค่า mdBook
├── src/                         # เนื้อหาหนังสือและสารบัญ
├── theme/css/custom.css         # รูปแบบเพิ่มเติม
└── theme/js/guide.js            # พฤติกรรมประกอบกิจกรรมในคู่มือ
```

## ขอบเขตและข้อควรทราบ

ภาพและคำอธิบายบางส่วนอ้างอิงเอกสารกรณีศึกษา _จรรยาบรรณวิชาชีพด้านวิศวกรรมคอมพิวเตอร์ ตอน ด่านอัจฉริยะ_ ซึ่งจัดทำในปี 2012 เอกสารดังกล่าวใช้เป็นบริบทเพื่อเรียนรู้แนวคิดและองค์ประกอบของระบบเท่านั้น ไม่ใช่หลักฐานยืนยันการใช้งานระบบในปัจจุบัน กฎหมาย นโยบาย และข้อมูลเกี่ยวกับระบบจริงอาจเปลี่ยนแปลงได้ จึงควรตรวจสอบกับแหล่งทางการฉบับล่าสุดก่อนนำไปอ้างอิง

ผลจากระบบอัตโนมัติเป็นข้อมูลประกอบการตรวจสอบ ไม่ควรถูกใช้เป็นคำตัดสินโดยอัตโนมัติ เนื้อหาในหนังสือเป็นสื่อการศึกษา ไม่ใช่คำแนะนำทางกฎหมาย

## การมีส่วนร่วม

ข้อเสนอแนะเกี่ยวกับความถูกต้องของเนื้อหา การเข้าถึง หรือการปรับปรุงกิจกรรม สามารถส่งผ่าน GitHub Issues หรือ Pull Requests ได้ โปรดระบุบทหรือไฟล์ที่เกี่ยวข้อง พร้อมแหล่งอ้างอิงเมื่อเสนอการแก้ไขข้อเท็จจริงหรือข้อมูลด้านกฎหมาย
